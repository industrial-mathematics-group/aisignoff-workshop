# 0 · Before the workshop

Please do this before Thursday. It takes five minutes. If something doesn't work, tell Pascal by Wednesday.

## 1. A GitHub account in the organisation

- No account yet? Sign up at <https://github.com/signup>.
- Send your GitHub user name to Pascal. You'll get an invitation to the organisation
  **industrial-mathematics-group** by e-mail: **accept it** (it expires after 7 days).

## Choose One:
### 2a. Select your own repository to set up

1. Check if the repository is already in our organization
2. If not: Go to **Settings** → **General** → **Transfer ownership** (Danger Zone on the bottom)

### 2b. Create your workshop repository

1. Go to <https://github.com/organizations/industrial-mathematics-group/repositories/new>
   (or **+** at the top right → **New repository**, and choose **industrial-mathematics-group** as the owner).
2. **Repository name:** `workshop-` and your name, e.g. `workshop-jane-doe`.
3. **Public.** (GitHub Pages and Zenodo need a public repository.)
4. Leave everything else as it is: no README, no `.gitignore`, no licence, no template.
5. **Create repository.**

You'll see an empty page with "Quick setup". That's right: we fill it together on Thursday.

> It has to be in the organisation, not under your own account: the group's checks and the IMGAgent
> assistant only work for the organisation's repositories.

## 3. Bring

- A laptop with a current browser (Chrome, Firefox, Edge or Safari).
- A **Zenodo Sandbox** account helps for part 6: open <https://sandbox.zenodo.org>, **Log in → Log in with
  GitHub**. It's free and only for practising.

Optional, for later: [GitHub Desktop](https://desktop.github.com/), an app that keeps a copy of a repository in a
folder on your computer. We won't need it.
